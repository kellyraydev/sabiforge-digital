# Supporting pages — next phase

This phase extends the approved SabiForge homepage visual language across the supporting agency experience. The work stays on `codex/sabiforge-premium-visuals`; PR #1 remains draft.

## What changed

- Work keeps all four conceptual studies and their functional demonstrations, with a new editorial portfolio index cover and stronger route framing. “Studio concept” labels and the fictional-work disclaimer remain explicit.
- About gains a warmer studio composition using abstract interface panels and preserves the existing honest studio narrative, philosophy, collaboration approach and no-invented-staff policy.
- Services overview and all ten service detail routes now have route-specific editorial signal panels, clearer visual entry points and the existing enquiry pathways/deliverables.
- Pricing gains a premium scope visual while preserving package names, standard prices, founding-client logic, comparison rows, exclusions and the mobile one-package-at-a-time comparison.
- Contact gains an enquiry visual panel while preserving the current browser-only brief assembly and email/WhatsApp handoff. Copy continues to avoid implying submission before the visitor sends it.
- Process and Shopify gain page-specific compositions. The draft legal pages were left readable, honest and marked as drafts.
- A PNG Open Graph asset is included at `/assets/og-sabiforge.png`, with the SVG source retained for provenance and future edits.

## Asset provenance

`EditorialSignal.astro` is an original CSS composition built from the approved SabiForge palette, geometry and typography. It contains no client logos, stock photography, testimonials, employees or business-result claims. The existing generated portrait remains limited to the approved art-direction use and is never identified as an employee.
